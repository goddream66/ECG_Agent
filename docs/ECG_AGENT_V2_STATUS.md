  新追踪器不补入未请求证据、不复制旧事件结论。

- 全部 552 个新记录级检查点通过文件哈希、证据引用、来源代码、时间权限及实际调用数审计。
- 汇总包含 38 个方法/设置，按记录配对 Bootstrap 2,000 次；主配置另与两窗、双通道和简单滞回配对比较。

- 初始 `runs/ecg-events-v1` 是修复“无活动事件时临界阴性被跳过”前的开发尝试，

## 真实 CPU 成本

环境沿用 CPU 版 PyTorch，8 个进程、每进程 2 个 Torch 线程，没有下载模型或安装 CUDA。
整个真实推理工作池耗时约 3,563 秒（59.4 分钟），共执行 536,251 次网络推理。

| 设置 | 真实模型调用 | 神经网络服务时间之和/秒 | 记录服务时间之和/秒 |
|---|---:|---:|---:|
| ECG1 新策略 | 99,454 | 5,498.535 | 5,653.295 |
| ECG1 固定双通道 | 168,648 | 8,667.281 | 8,766.677 |
| ECG2 新策略 | 99,501 | 5,049.592 | 5,209.673 |
| ECG2 固定双通道 | 168,648 | 8,009.070 | 8,101.595 |

相比固定双通道，模型调用减少约 41%，实测神经网络服务时间之和减少约 36.6%/37.0%。
这是并发 CPU 下的服务时间测量，各组资源争用和热状态不同，不能直接宣称单请求延迟
或独立部署墙钟时间同比改善。模型加载按工作进程单独记录，不重复累加到每条记录。

## 结果定位与限制

- AFDB 23 条记录、约 234.3 小时、285 个 AFIB+AFL 事件。整库已被用于开发观察，
  本轮结果不属于盲测。缺少确认的受试者映射，统计以记录为单位并披露残余身份风险。
- 23 个完整任务均包含阳性事件，不能据此声称已验证纯阴性整条记录特异性。
- 模型分数未校准，质量为启发式；不存在已经完成的学习型停止或临床风险保证。
- 严格约束为已完成窗口可见。离线窗口内滤波未变成样本级在线滤波。
- 真实成本在 CPU 并发工作进程下测量，资源服务时间与独立请求延迟分别解释。
- 工程交付 M0—M1-C 已完成；复杂复核没有在所有指标和通道上超过简单滞回。
  后续 M2 应以这些强基线为对照，而不是只与较弱的旧 Adaptive 比较。
