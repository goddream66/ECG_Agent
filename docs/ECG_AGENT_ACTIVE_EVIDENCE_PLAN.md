# ECG Agent 主动补测与事件复核方案

目标是验证**事件间隔补测能否恢复真实 AF/AFL，以及 Qwen 能否比规则更有效地选补测动作**。沿用十秒窗、`quality-as-hint` 和事件追踪器。第一轮只处理两个已确认事件之间的间隔。孤立候选、单个事件的起止边界、没有形成候选的漏报，留给其他实验。

## 1. 按有效性验证的实验顺序

**按顺序开跑。前一步的证据不足以支持下一步时，先定位问题，再决定是否继续。错位窗是独立验证项。原窗补测有效时，即使错位窗无效，也可以用原窗动作比较 Qwen 和规则。**

| 顺序 | 先回答什么 | 所需对照 | 什么时候进入下一步 |
| --- | --- | --- | --- |
| **0. 冻结基线和检查候选** | 旧结果能否复现？当前候选能覆盖多少真实断点？ | 原 `quality-as-hint`（A）；同一批候选、统一裁决且零补测（B0）。 | 基线差异能解释，且独立标注确认候选中有可恢复的间隔和真实中断。候选覆盖不足时，先改候选触发。 |
| **1. 验收历史补测工具** | 能否读取正确的已到达波形，产出可复现的分数和质量结果？ | 合成测试；原网格缓存与重新评分；已知案例的小样本联调。 | 时间、导联、指纹、质量归属、失败回退和预算检查全部通过。 |
| **2. 验证原窗补测本身** | 多拿到一路分数或质量，是否真的能改善事件？ | B0 对候选内原窗全补测（D）。若 D 有效，再跑固定规则预算组（B），比较 B 与 B0。 | D 恢复了真实时间且误连代价符合预先约定。若 D 有效但 B 无效，保留 B 作为同预算对照，并用 D 的轨迹判断两次预算是否有机会补齐关键证据。 |
| **3. 单独验证错位窗** | 错位评分能否帮助选到更有用的下一次测量？ | 同一固定策略、同一预算，比较仅原窗与开放错位窗的表现。 | 错位窗只有在改善最终修订或节省测量时，才进入后续主动作菜单。只看到分数变化时，将其报告为切窗敏感性。 |
| **4. 比较 Qwen 和规则** | 在相同预算下，Qwen 能否做出更好的补测选择？ | Qwen 组选补测（C）对固定规则组（B）。两组使用已通过前述验证的同一动作菜单。 | 用配对结果判断是否有增益。结果不确定时报告不确定性，避免从个别案例推断整体收益。 |
| **5. 外部验证** | 在开发集上看到的收益能否迁移？ | 冻结最终配置，在从未用于调参的 LTAFDB 记录重跑关键对照。 | 报告跨库的收益、误连和成本，包括结果下降的记录。 |

### 步骤 0 · 固定候选和零补测对照

- 用 AFDB 23 条有波形的完整记录（本项目约 234.28 小时），分别以 ECG1、ECG2 为主导联。沿用十秒窗、`0.6/0.4` 滞回、右侧事件确认后触发及 60 秒间隔上限。复用 `afdb-quality-full-20261118T034433Z` 和 `afdb-event-review-b8d284c` 中的基础结果。以前一轮 263 对候选，以及 A 的 F1（ECG1 0.6761，ECG2 0.6698）作回归检查。候选按记录、主导联、前后事件 ID 和触发游标对齐。
- A 保存原始追踪结果，不追加修订。B0 只用冻结证据执行后续各补测组共用的裁决器。复用旧裁决时应复现 10 次有证据的连接。若裁决器定义有改动，另存配置并先报告 **B0 与 A** 的差异。
- 在评价侧用有效节律标注把候选间隔分为**完整位于同一参考 AF/AFL 事件内、含非 AF 时段、标注不足**。统计各类候选和时长，并单列没有形成前后事件对的漏报。之前有 78 对真实连续间隔未满足旧合并条件，其中 64 对出现持续模型反对信号，优先用于定位证据瓶颈。这些标签只参与事后评价。AFDB 的已知波形缺块和节律标注有效范围分开登记。[PhysioNet AFDB](https://physionet.org/content/afdb/1.0.0/) · [项目参考标注加载](../src/cardioagent/ecg_agent/evaluation/references.py)

### 步骤 1 · 工具验收和小样本联调

| 检查 | 测试办法和通过标准 |
| --- | --- |
| **历史读取与因果性** | 原窗 `160–170 s` 偏移后必须实际读取 `155–165 s` 或 `165–175 s`。游标为 `170 s` 时拒绝后者。在 `210 s` 补测 `160–170 s` 时，结果只对 `210 s` 及以后可见。修改游标之后的信号，之前的输入、证据和修订均一致。 |
| **原网格复现** | 对固定的一组已有分数窗，按原坐标运行同一预处理和 ECGFounder，比较两项分数及阈值分类。预先登记同设备容差；CPU 与 GPU 的阈值翻转单列，区分数值精度与窗口切错。 |
| **波形缺失和质量归属** | 验证缺失、越界、错误导联和采样数不符的返回状态。分别测原窗和偏移窗，检查质量结果只归到自己的实际区间。质量告警后保留原分数，未测和失败单独保存。 |
| **执行与记忆** | 测重复动作、非法 ID、预算耗尽、模型错误和工具失败。检查重复动作不触发前向，失败有日志且不破坏基础结果。历史测量、两层记忆、动作和最终修订可用证据 ID 回放。 |
| **错位高分的反例** | 构造间隔实际已中断而错位窗覆盖前一事件的例子。即使分数升高，裁决也必须保留缺证据的间隔。原窗和错位窗的共有时间只计一次。 |

先用合成输入覆盖边界，再用 `05121` 检查评分与质量的自动绑定，用 `06995` 检查导联分歧的处理。各案例用于复现行为和查日志。联调通过后，再运行完整记录。这里参考 ECG-Scroll 的已到达信号权限、回看成本和带游标写入。[ECG-Scroll §3.1、§4.1、§4.4](https://arxiv.org/html/2609.33117v1)

### 步骤 2 · 不接 Qwen，先测原窗补测

1. D 对每对候选补齐在触发游标下可取得的**原十秒窗**评分与质量，如补测备用导联缺少的分数。复用当时已取得的观测，保留失败。所有新证据交给与 B0 相同的裁决器。
2. 比较 **D − B0**。主看恢复的真实 AF/AFL 秒数与新增的非 AF 秒数，辅助看 F1 和长事件碎片。D 是当前工具与裁决器在充分测量下的结果。额外测量可能带来冲突，因此 D 不是数学上限。
3. 若结果没有可接受的改善，按「候选有没有覆盖断点 → 工具有没有取得新信息 → 裁决器有没有使用新信息」检查。按缺评分、缺质量、原本两路冲突或无波形分组。已有两路完整评分仍持续冲突的候选，补齐原窗通常没有新的评分可取。需要进一步研究时，再验证 RR 或形态等不同证据。
4. 若 D 有改善，运行 B。首轮将**每对间隔最多两次新增测量**作为主预算。评分、质量各计一次，已取得的缓存读单列。固定优先补足只差一项即可形成支持的窗口，再处理需要两项测量的窗口，同优先级按时间和导联排序。若要从 D 估计两次测量是否足够，在评价侧用 D 的结果枚举至多两项的组合，并用同一裁决器重新执行。D 的执行顺序本身无法给出最少调用数。**如果两次测量下没有可行修订，先改工具集合或预算，再比较 Qwen。**

### 步骤 3 · 在同一预算下验错位窗

先观察 `±5 s` 是否使分数跨阈值，再检查高分窗覆盖了多少间隔和两侧原事件。随后用**原窗补测规则**与**允许先测错位窗、再用结果选择原窗补测的规则**做配对比较，裁决器和预算一致。提前固定路由，例如错位窗分数过开始阈值时，优先补它覆盖的、尚有缺项的间隔原窗，否则沿用原窗优先级。错位动作消耗一次测量，只在剩余预算允许取得能改变裁决的原窗证据时进入主菜单。若缺少可执行的下一步，错位评分只用于诊断。

例如原窗为 `160–170 s`，`155–165 s` 的高分可能来自已经被确认的 `155–160 s`。因此保留该结果的测量区间和重叠关系。只有实际间隔中的原窗证据满足统一裁决条件，才生成连接修订。**若错位组只有分数翻转、没有恢复时间或成本收益，Qwen 主实验只开放通过验证的原窗动作。**

### 步骤 4 · 固定证据和裁决，只换动作选择器

- B 与 C 从同一候选快照出发，使用同一工具、动作生成逻辑、缓存规则、预算和裁决器。B 选固定优先级动作，C 由 Qwen 输出一个合法动作 ID 或 `STOP`。运行时负责校验、执行和绑定证据，模型的解析失败、超时、停止及回退都保留在统计分母内。
- 每次补测后运行同一个裁决器。已具备充分证据的候选直接处理；只有仍有疑点且有可执行的新动作时才调用 Qwen。两组完整保留无候选或未修订的记录。主比较为 **C − B，预算 2**。有明确价值后再扩展预算 1、4 的成本曲线。
- **结论判定**以恢复秒数和新增非 AF 秒数成对报告。开跑前登记可接受的误连代价；如果缺少依据设非零界限，按保守标准展示结果，即恢复增加且误连未增加，或在相近结果下使用更少的新测量。若覆盖与误连都增加，报告每多恢复 60 秒引入的非 AF 秒数；若区间宽或仅少数记录有效，结论保留为探索性。同预算比较的依据是主动特征获取对测量选择与成本的联合评价。[Shim 等，NeurIPS 2018](https://proceedings.neurips.cc/paper/2018/hash/e5841df2166dd424a57127423d276bbe-Abstract.html)

### 步骤 5 · 外部验证

若 AFDB 显示可重复的收益，冻结候选规则、工具、预处理、阈值、裁决器、提示词和预算，再在 LTAFDB 新记录上重复关键对照。适配采样率、通道和节律标签，核对与工具验证集的记录重叠。若形态工具用过 BUT PDB，注意其中含 LTAFDB 来源片段。AFDB 是反复参与开发的探索集。[PhysioNet LTAFDB](https://physionet.org/content/ltafdb/1.0.0/) · [BUT PDB 来源](https://physionet.org/content/but-pdb/1.0.0/)

## 2. 实验评分和产物

- **主要结果**。用各组预测减去 B0 预测获得新增覆盖，在有效标注范围内与参考 AF/AFL 相交得到恢复秒数，其余为新增非 AF 秒数。若某组撤销了 B0 已覆盖的时间，另算移除的真 AF/AFL 秒数和非 AF 秒数，同时报告净变化，避免只统计新增的收益。时间区间按并集统计。只有事件身份被关联时，未补足的未知时间仍保持未知，AF/AFL 负荷不变。
- **全记录指标**。沿用预测顺序和一对一贪心 IoU 匹配，AFDB 阈值为 `0.5`。分别报告事件 F1、TP/FP/FN、长事件碎片、时间召回与非 AF 报警分钟。对未知时间和跨越多个参考事件的连接单独计数。依据是项目现有评分器和 ECG-Scroll 的区间评价。[项目评分代码](../src/cardioagent/ecg_agent/evaluation/metrics.py) · [ECG-Scroll §3.3 与附录 B](https://arxiv.org/html/2609.33117v1)
- **统计与成本**。ECG1、ECG2 分开报告，按记录配对 Bootstrap 2,000 次，种子 `20261114`，报告 95% 区间。若汇总两个主通道，两路同一记录共同重采样。有可靠的受试者映射时按受试者分组。分别记录实际模型前向、质量调用、缓存命中、Qwen 调用和运行耗时。离线冻结游标时，只报告实际复核计算耗时，不把它当成在线报警延迟。
- **保存内容**。每次开新运行目录。清单登记代码、数据、模型、预处理、候选集合、提示词、动作预算和裁决器指纹。保留 `候选 → 动作 → 工具结果 → 区间修订` 的日志与原报警时刻，逐记录指标和汇总表由评价侧生成。画图展示恢复、误连和错位高分但没有修订的典型案例。

## 5. 错位窗实验结果（2026-11-18）

在同一份 AFDB 质量回放上，以两条记录联调后运行完整的 23 条记录和 263 对候选。错位评分使用原来的单导联 ECGFounder 权重及十秒预处理，偏移为 `±5 s`，在原右侧事件确认游标下读取波形。CPU 全量实验用时约 163 秒。

| 主通道 | 诊断错位评分次数 | 由低分升至 ≥0.6 | 由 ≥0.6 降为低分 | 两次预算下 B / B_shift F1 | 两组各自新增工具调用 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ECG1 | 1,496 | 198 | 20 | 0.6793 / 0.6793 | 170 |
| ECG2 | 1,512 | 192 | 23 | 0.6772 / 0.6772 | 188 |

诊断组共 3,008 次成功评分，433 次跨越 `0.6`。390 次向上翻转中，314 次的实际测量窗同时覆盖了**间隔外的参考 AF/AFL 时间**。这只能说明向上翻转经常伴随边界外阳性覆盖，无法确定高分由哪一段波形贡献。诊断结果按候选及导联请求计数，重叠的请求不能作为独立样本。

**两次预算对照没有实际触发一次错位动作。** 10 对已有充分证据，246 对仍有至少两个原窗缺合格支持，其余 7 对也无法靠一次原窗测量补足支持。因此，花一次预算做错位评分后，剩余一次原窗补测无法满足现有整段裁决条件。两组实际走了相同动作，新增真实 AF/AFL 和非 AF 时间的组间差值均为零。该结果证实了分数对窗口起点敏感，同时暴露了当前预算与裁决条件的限制。错位评分作为选测量线索是否有效，仍需要在能实际触发的对照中评估。
