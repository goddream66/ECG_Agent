# 延迟复核单窗候选事件

AFDB 06426 和 LTAFDB 101 的日志中，模型登记了一个有支持的候选。后续窗口反对 AF/AFL 时，原接口可以撤销候选或等待，无法在此时发布上一窗已经结束的事件。本实验单独验证这种延迟发布能否找回可匹配的短事件，以及它产生的额外误报。它也可能把伪差或长事件中的分数波动当成一次独立事件。

## 候选与时钟

冻结双导联两窗开、两窗关基线。使用两路各自的 max(AF, AFL) 与 0.5 比较。连续四个无缺失的十秒窗口依次出现双路低、双路低、双路高、双路低时才产生一次复核机会。前两个低窗确保基线当前没有开放事件。任何导联缺测、分歧或时间不连续都会打断这个模板。样本清单仅依据已到达的 Founder 结果生成。将十秒高分窗作为可发布的估计区间，实际发布时间是第四窗的末尾，即高分窗到达后再等十秒。始终保留这两个不同的时间。

## 数据与实验

- 使用既有 AFDB 分组。14 条记录仅用于构建简单对照。8 条预留记录及单独的 04936 分开报告。每条完整记录中的全部触发机会均纳入，零机会的记录保留在整记录分母中。这些开发记录此前已有其他实验，不能声称是首次接触的外部数据。
- Qwen 可发布上一窗的短事件、撤销候选或标为不确定。窗口事实与事件发布时间写入日志，未决和动作错误都单独计数。各组共用同一最终判断提示和工具接口。
- 对比仅看四个对齐窗口、固定补齐两路左右错位窗、按需补测三种 Qwen 条件。按需组最多追加两次测量，每次选择一个导联和相对高分窗 −5 或 +5 秒的十秒区间。它们都在复核时刻之前完整到达。重叠窗口共用波形。备用导联及重叠窗不同意时，允许保留不确定。保存每次请求、真实返回、生成成本及最终建议。
- 对照包括所有候选一律发布、全部不发布、两路高分窗均达到 0.8 才发布，以及在 14 条指定记录上拟合的同证据逻辑回归。对齐、固定错位和按需取得的证据分别对比。单窗开启、两窗关闭和原双窗开关基线另行保留。
- 参考区间只进入评价。按 IoU ≥ 0.5 一对一匹配，区分独立匹配、只与更长事件部分重叠、完全无重叠。报告加入候选前后的整记录 Micro F1、TP、FP、FN 和非目标报警秒数。另报候选中命中/误报、拒判和错误、实际补测次数、LLM 调用与耗时。后验最佳选择仅表示固定候选区间的可达上限。

## 判读

一个触发点在串行回放中的测量预算不得跨病例共享。只有在相同波形和可见历史下与强规则比较，才能判断收益来自 Qwen 的选择、额外的实测信息还是延迟发布权限。若候选中可匹配的事件太少，首先报告这一覆盖限制。实验性选择在独立数据验证后再考虑替换持续扫描主线。
