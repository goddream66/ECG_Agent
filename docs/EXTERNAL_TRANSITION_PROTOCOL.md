# LTAFDB 连续片段的起止与稳定性对照

此前独立抽取的四段二十分钟记录中，一段持续 AF/AFL，三段全程无目标节律。它们检验了稳定期监测，片段内部真实起点和终点的数量均为零。本实验在读取新记录的预测前确定以下设计。

## 选取片段

- 排除首轮 12 条 LTAFDB 记录和连续回放的 4 条记录，核对两个清单的来源哈希。每条新记录最多使用一次。
- 对每条记录建立不重叠的 300 秒时间格。起始偏移取自记录标识的固定散列，对齐到 10 秒，保留整段处于有效标注范围内的时间格。
- 离线分为四类。第一类有一段 5 至不足 30 秒、首尾都在片段内的参考事件。第二类有持续至少 60 秒的参考事件在片段内结束。第三类一段参考事件覆盖全部 300 秒。第四类整段无 AF/AFL。按此优先级归类。每类按固定散列依次抽取两条记录，记录内同样按散列选一格。
- 每段从空账本开始，连续处理 30 个窗口。参考标注、分组和抽取理由仅进入离线评价。评分保留片段中的全部事件。该分层样本可比较边界处理与误报，不能直接用于估计总体患病率或未分层记录的平均表现。

## 方法与指标

Agent 使用已接受支持证据的事件记忆、按需导联和边界补测，本轮使用逐条说明证据引用问题的重试反馈。向 Qwen 提交的生理测量和真实耗时分开记录。经验分箱、阈值、模型参数、测量预算及固定十秒到达间隔沿用前一轮。每种方法使用相同的波形、模型权重、片段范围及参考区间。

主对照在两个导联于同一窗均达到 0.5 时产生支持，均低于 0.5 时产生反向观察，连续两窗确认开启和关闭。另比单窗开启、双窗关闭，规则按需测量第二导联，以及仅在 Agent 实际获取的对齐测量上执行的规则。

主结果为 IoU ≥ 0.5 一对一匹配的事件 Micro F1、TP、FP、FN。附报片段 Macro F1、各层结果、非目标误报秒数、遗漏目标秒数、在线匹配数和负荷误差。起止误差仅统计匹配且相应边界在片段内部的事件，并列出分母。报告真实 Founder/Qwen 调用、token 和逐记录累计耗时。保留所有失败片段及异常动作。该实验对规则与 Agent 做配对比较，单个案例中取得改善仍需独立重现。
