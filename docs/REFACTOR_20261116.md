旧 API 以模块别名或惰性导入兼容，旧脚本转交包内实现。不要继续在兼容文件中添加算法。旧状态文档原文移入 docs/history/multimodal，根目录保留指向文件；已有实验产物和研究计划保留。

## 验证与运行

本地及服务器各通过 101 项测试，保留原 95 项断言。CPU、单 GPU、缓存三种模式分别与重构前相同输入比较：模型分数、工具请求顺序、逐窗判断和最终事件区间一致。真实模式核验前四条记录各前 300 秒、ECG1/ECG2 两种主通道、新策略及固定双通道，共 16 个记录作业和 740 次模型调用；CLI 另检查一条记录前 60 秒。缓存检查 48 个作业。固定证据检查第一条记录的完整旧轨迹、两个主通道、四种变体，共 8 个作业。

验证范围是有阳性和阴性窗口的工程回归检查，没有重新运行全量研究实验，也不意味着算法效果提升。旧 fixed 回放按完整已保存轨迹消费证据，原适配器不按 --duration-s 截短；本次验收使用 fixed-full 完整轨迹目录，早期带 duration 参数的 fixed 试跑不作为时长受限验证依据。

```bash
source /home/gaojiajun/ECGagent/activate.sh
./run_server_experiment.sh live --limit-records 4 --duration-s 300
# 全量推理：同一命令省略最后两个限制参数
# GPU 切换：ECG_AGENT_GPU=3 ./run_server_experiment.sh live
# CPU 对照：ECG_AGENT_DEVICE=cpu ./run_server_experiment.sh live
```

输出自动写入 data 盘新的 runs 子目录，也可通过 ECG_AGENT_OUTPUT 指定 data 盘 runs 下的目录。断点续跑要求代码、参数、输入、模型指纹一致；重构前的检查点不能直接当作新版本继续运行。源码备份 source-before.zip 和部署后的源码清单保存在上述 migration 目录。
