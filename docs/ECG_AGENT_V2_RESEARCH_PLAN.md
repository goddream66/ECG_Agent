## 1. 研究目标与范围

研究在只允许访问已到达 ECG 的条件下，如何根据可追溯证据学习下一次测量的价值，
决定何时停止本轮复核，并连续维护 AF/AFL 事件。

近期交付范围为 M0 与 M1-A/B/C：保持已有 ECGFounder 权重、NeuroECG 预处理和
10 秒离线输入缓存，建立可独立验证的 AF/AFL 事件追踪系统。主通道每 10 秒产生分数，
规则控制器选择额外测量、等待和事件动作。近期不训练新分类头、不微调 ECGFounder，
不接入 LLM，不实现多模态或多 Agent；这些工作不作为本轮交付前提。

后续 M2 研究证据获取价值与停止风险的学习，M3 检验 LLM 的增量作用，M4 做冻结后的
外部验证。研究单位为一次复核决策及其所属事件。规则的 STOP_REVIEW 从 M1 开始存在，
学习型停止从 M2 才开始，二者分别标记。

任务保持 AFIB+AFL 合并的区间定位、持续状态跟踪及负荷估计。PVC 在主假设得到支持后
作为迁移任务；已有 AF 区间与 AF 负荷共用证据，不把它们计作两个独立诊断任务。
ECG1、ECG2 是数据中的通道名，解剖导联未知，不擅自命名为标准 I/II 导联。

## 3. 三个核心假设

| 假设 | 必须得到的实验支持 | 失败时的解释 |
|---|---|---|
| H1 事件状态能改善连续性 | 先在完全相同的证据轨迹下隔离追踪器贡献，再在匹配预算下比较闭环复核与两窗、固定双通道及简单平滑基线；同时报告非 AF 时间报警和短事件召回 | 状态设计或基础感知仍不足，不能仅用合并区间宣称改进 |
| H2 学到的价值能改善复核效率 | 相同风险、覆盖率、延迟约束下，工具调用成本更低，或同等成本下错误更低 | 学习策略未优于规则调度 |
| H3 证据状态能改善 LLM 决策 | 相同骨干、工具、预算下，结构化证据与审查优于原始历史，并在独立记录/外部数据验证 | LLM 未提供可验证的增量收益 |

主要报告风险—成本—覆盖率及延迟的权衡。没有预设必须取得某个提升幅度。
允许风险、召回和延迟的容忍度在查看外部测试之前登记并冻结。
工程功能是否完成与研究假设是否获得支持分别验收；不要求所有指标同时提高才算代码完成。
状态记忆针对暂时中断，不保证纠正连续多窗或双通道一致的感知错误。必须保留持续错误
高分、持续错误低分、真实短阴性间隔及极短事件作为反例，防止保持机制放大错误。

## 4. 时间语义与三类停止

1. STOP_REVIEW：停止当前时刻的额外工具调用，提交当前判断，随后继续接收信号。
2. END_EVENT：判断已有发作结束，记录估计结束位置和做出判断的时刻。
3. END_STREAM：回放自然到达记录末尾。

确认 AF 持续后可以 STOP_REVIEW，事件状态仍为持续。停止复核不隐含事件结束。
暂时缺失或冲突保留为未知证据区间。最终同时保存报告区间及区间内部的未知掩码，
报告对未知区间的处理口径和敏感性分析。

每个缓存窗在其 end_s 时刻可用。质量、RR、模型、预览、摘要和校准器输入都遵守此边界。
第一版的任意历史访问通过证据记录进行，波形工具仅访问当前完整窗口。
决策不能读取数据文件路径或全局分数表；控制器只接收脱敏的当前观察与允许动作。
若以后开放有限回看，必须显式指定保留长度并记录重测成本。

所有窗口统一使用半开区间 [start_s, end_s)。分别保存 candidate_start_s、first_seen_at_s、
confirmed_at_s、estimated_end_s 与 end_decided_at_s；来源窗口与时间单位不可省略。
例如 10 秒收到 [0,10) 阳性、20 秒收到 [10,20) 阳性，若两窗确认，则估计起点为 0 秒，
首次观察为 10 秒、确认时刻为 20 秒。确认后允许追加起点估计，历史写入时间不得回写。

若 100 秒收到 [90,100) 首个可靠阴性，110 秒收到 [100,110) 第二个可靠阴性，示例规则
可把结束位置估为 90 秒、实际结束判断记为 110 秒；这只是窗口级估计，不是精确生理边界。
具体边界约定在 M0 登记，各方法共用，不把观测时刻直接当成窗口起点。
因未知超时或自然记录结束而停止追踪，不等于获得了可靠 END_EVENT 证据。

## 5. 证据、信念状态与审查

### 5.1 证据记录

每条 Evidence 包含 evidence_id、run_id、task_id、record_id、通道及解剖导联已知性、
原始样本范围、窗口起止、available_at_s、observed_at_s、工具/模型/预处理版本、
原始分数或测量、质量及缺失信息、获取成本。权重、处理配置和数据哈希存于运行清单，
证据引用清单指纹，避免每条结果重复保存整份来源元数据。
数值来源与最终事件判定分开保存。相同输入重复测量不当作新的独立证据。
双通道分数共享一个模型，需标注相关来源；不能把通道一致直接换算成独立概率相乘。

修复现有只由 origin、cursor 和会话内序号构成的 ID：新 ID 必须包含运行、任务/记录命名
空间及不碰撞的调用标识，验证跨通道、跨窗口和重复运行唯一性。重试记录另有 retry_of，
缓存复用保留 source_evidence_id 或输入指纹，不伪装成新的独立观察。

原始 Evidence 追加保存；evidence_role（支持/反对/未知）、decision_reason、引用的
evidence_ids、策略版本和解释时刻属于独立的 EvidenceAssessment/Decision 记录。
角色依赖当前任务、阈值和状态，重解释不能覆盖原始分数。事件更新引用这些记录。

现有 ToolResult 已覆盖部分字段，增加来源指纹及证据间关联，不另建重复日志系统。
原始 RR 与清理掩码均保留。

### 5.2 当前信念状态

维护当前阶段（无活动事件、待确认、持续、结束待确认、未知/待复核）、候选起点、
最后确认支持时刻、估计结束时刻、已确认区间和未知区间、最近多窗证据摘要、
尚未解决的问题、可访问动作和剩余预算。
事件阶段、证据可用性与终止原因分别表达，不强制压成一个枚举。保留 event_id、
是否已确认、最后可靠阳性、连续可靠阴性计数、未知时长以及状态转换日志。

学习模型可使用工具分数、分数变化、历史支持与反对持续时间、事件持续时间、
质量、RR 统计及缺失掩码、跨通道差异、已请求动作。未调用工具的结果必须为未知，
禁止从完整缓存中提前填入状态。

### 5.3 审查器

确定性审查先检查证据 ID 存在性、时间权限、单位、原始数值引用、状态转换与缺失语义。
可选 LLM 审查检测推理中的遗漏和冲突；新增测量仍通过同一工具运行时执行并计成本。
内部一致性、语言置信度与概率校准分别评价。审查通过表示满足所定义的检查条件。

## 6. 先建立事件连续性基线

### 6.1 事件生命周期与不变量

建立显式事件状态机，分别实现进入、维持和退出条件。阶段为 IDLE、CANDIDATE、
ACTIVE、PENDING_END 和 UNKNOWN_HOLD；CLOSED/REJECTED 是事件终态，不与控制器
返回 IDLE 冲突。另记录终止原因 confirmed_end、candidate_rejected、unknown_timeout、
candidate_timeout 或 stream_end，后两类超时及记录结束不标成可靠生理结束。

| 当前阶段 | 已获得证据/条件 | 处理 |
|---|---|---|
| IDLE | 可用阳性 | 建候选及 event_id，保存起始窗口和实际观察时刻 |
| CANDIDATE | 达到预登记确认条件 | ACTIVE，追加确认记录并保留候选起点 |
| CANDIDATE | 可靠阴性 | REJECTED；不导出已确认 AF 区间 |
| CANDIDATE | 未知 | 保留未确认身份并计超时，不能自动升级 ACTIVE |
| ACTIVE | 可用阳性 | 维持事件，追加支持区间 |
| ACTIVE | 首个可靠阴性 | PENDING_END；保留事件身份并记录待定边界 |
| ACTIVE/PENDING_END | 缺失、质量不足或通道冲突 | UNKNOWN_HOLD，记录未知区间及进入前阶段 |
| PENDING_END | 可用阳性 | ACTIVE，撤销待定结束并保留原 event_id |
| PENDING_END | 连续可靠阴性满足退出条件 | CLOSED，分别记录估计终点和实际判断时刻 |
| UNKNOWN_HOLD | 宽限内可用阳性 | 按原确认状态恢复 ACTIVE 或 CANDIDATE，保留身份 |
| UNKNOWN_HOLD | 可靠阴性 | 重新进入结束确认或否定候选，不把未知当作负证据 |
| UNKNOWN_HOLD | 未知超过上限 | 未解决终止，保留未知原因，不伪造正常或确定结束 |
| 任意非终态 | END_STREAM | 归档候选或未结束事件；已确认事件标记记录末尾截断 |

“可靠阴性”是预登记的可操作规则：质量检查通过且满足所选阴性分数/复核条件，
不等同于人工诊断真值。双通道冲突默认是未知。缺失或冲突打断连续可靠阴性计数，
不能把两次相隔多个未知窗口的阴性直接称为连续两窗。
所有转移通过追加式修订记录 evidence_ids、decision_reason 和 recorded_at_s。
事件关闭后恢复阳性需新建 ID，不能修改旧事件以隐藏中断。

### 6.2 参数、未知区间与输出

隔离记忆的首轮对照保持原阈值 0.5 与原证据轨迹不变；候选进入和结束确认窗口数
以两窗作为初始规则，未知宽限比较预登记的 0、10、20 秒。参数选择只使用内部验证折。
再单独对照不同进入/退出阈值的滞回方案，避免把阈值变化算成状态记忆收益。
允许同窗双通道支持提前确认时，必须作为单独变体报告，不能混入两窗确认基线。

已确认事件保存 event_id、confirmed_support_intervals、unknown_intervals 和按冻结
规则导出的 reported_intervals。保持身份不代表未知时间被确认 AF。
若导出规则跨越未知间隔，明确计入哪些时间，并报告时间级误报、未知占比和负荷误差。
超时/记录末尾事件保留 unresolved/right-censored 标记；预测导出只能延伸到当时已到达
且规则允许的时间。没有后续真实阴性时不计算为已知终点，不用记录末尾伪造零结束误差。
未确认候选与已确认事件采用不同的超时结果。无上限保持事件不作为可用方案。

### 6.3 状态感知的规则复核

规则同时关注临界阳性、临界阴性、ACTIVE 中突发阴性、质量下降和已取得的通道冲突。
未请求第二通道时，其质量与分数仍为未知，不能凭预计算表决定是否调用。
在共同预算下考虑第二通道评分、质量检查或 WAIT_NEXT；每条分支保存触发原因、
请求动作、失败处理与最终状态。证据充分时 STOP_REVIEW，流和事件追踪继续。

RR 在 M1 默认不进入核心裁决路径，先作为独立可选消融。加入时必须登记具体可重复
规则，证明其数值确实改变判断，并报告对非 AF 不规则节律的错误；不能只调用后记日志。
RR 变化不是 AF 的独立确诊证据。

必须保留简单时间平滑、独立进入/退出阈值的滞回和固定最大间隔合并对照。
它们与复杂追踪器共享原始分数、允许的时间范围和边界约定。

## 7. 学习下一条证据的价值和停止风险

### 7.1 动作空间

- 获取当前窗第二通道的 ECGFounder 分数。
- 测当前窗的质量或原始 RR。
- WAIT_NEXT：等待下一窗，继续更新主通道分数与信念状态。
- STOP_REVIEW：提交当前状态判断并停止本轮额外复核。
- END_EVENT：提交事件结束判断，保留当时的证据及时间。
- DEFER：当前证据不足，保留未知状态并继续监测。

主通道基础评分成本计入总成本。WAIT 必须计入等待延迟和等待期间的基础评分成本。
DEFER 计入未判断覆盖率与延迟，防止策略通过无限待复核获得虚假的低风险。

### 7.2 训练数据

在训练记录中枚举一部分当前可行动作与短程后续路径，建立相同可见状态下的动作价值标签。
质量/RR/第二通道可在离线准备阶段计算潜在结果，但只有真实选择该动作后才能进入策略状态。
第一轮使用有限复核预算和短程 WAIT 搜索，预先设定训练预测范围；改变范围做消融。
不将有限深度的教师策略称作全局最优。

覆盖阳性、阴性、通道冲突、噪声、短事件、转换边界与长事件中断点。
按记录/受试者均衡采样和加权，防止长记录或长 AF 占满样本。
事件中途、边界窗、缺失窗的标签定义单独登记。使用窗口 AF 占用比例或明确的软标签，
不能把混合窗口无条件标成纯阳性。无标注与信号不可用分别标识。

训练标签可利用事后人工标注和未来实际测量结果来评价 WAIT 的收益，特征只能来自
当时已观察证据。未来标签和未来分数不进入输入。

### 7.3 模型与目标

先冻结 ECGFounder，训练小型动作价值网络及停止风险估计器，使用可行的动作掩码。

Q(s,a) = E[L_decision + lambda * C_tools + mu * C_delay | s,a]

L_decision 覆盖错误确认、错误结束、漏掉发作和未判断代价。
序列层面另报告定位、时长、事件碎片和边界损失，防止单窗正确而整段错误。
M2 首轮采用监督回归/排序训练，比较线性模型与小型 MLP；M1 不训练这些模型。
损失权重、拒绝代价和风险阈值由内部验证选择，绘制权衡曲线。

独立估计 STOP_REVIEW 后判断错误风险与 END_EVENT 的错误结束风险。
使用独立校准折校准风险，记录 Brier、可靠性曲线及错误排序能力。
停止由预测代价和允许风险共同决定；LLM 自报置信度仅作为候选特征。
风险约束是验证集上的统计估计，报告样本量和区间，不声称临床安全保证。
训练前登记 STOP_REVIEW 的当前判断/窗口标签口径及 END_EVENT 的错误结束容忍区间，
含混合窗口、缺标和未知的样本单独分层或排除并计数，不能默认都是正确停止。

## 8. LLM 的角色与实验

先接入冻结权重的一个 LLM，采用确定输出 schema 和可复现模型版本。
输入为任务、当前证据、事件状态、尚未解决问题和合法动作。
输出为动作、使用的证据 ID、未解决问题及简短理由。
控制器的全部工具调用进入 ToolSession，时间和预算约束由代码执行。

| 设置 | 目的 |
|---|---|
| 规则状态机 | 判断连续性本身的贡献 |
| 学习价值模型直接决策 | 判断小模型是否已能取得同等收益 |
| LLM + 相同可见证据的原始调用历史 | 作为结构化证据状态的表示对照 |
| LLM + 证据状态 | 判断 LLM 能否依据证据改善决策 |
| LLM + 证据状态 + 学习价值/风险 | 判断学习到的行动价值能否改善 LLM 的停止与复核 |
| 上一行加一致性审查 | 检验审查对证据引用、决策错误和额外成本的贡献 |

固定同一 LLM、预算、工具和预处理，采用配对记录对比。
报告工具调用数、token、LLM 实际延迟和可用覆盖率。
M3 完成这些冻结骨干对照后，再考虑轨迹 SFT 或强化学习，避免同时改骨干与策略使归因困难。

## 9. 数据协议

AFDB 已被反复分析，作为开发库。按记录实施外层交叉验证，模型训练、参数选择、
风险校准在每个外层训练部分继续分折，明确保留既往全库观察带来的探索性局限。
两通道和同一人的所有窗口始终归入同一折。核对已知受试者映射并登记分组方式。

LTAFDB 84 条本地记录作为下一阶段外部 AF/AFL 验证候选。
先核对原始标注、通道、采样率和缺失。其 128 Hz 输入用统一、已冻结的窗口处理规则
重采样。冻结标签口径、预处理、阈值、策略、LLM 提示词和指标之后再跑整库。
如果需要目标域适配，预先划出单独记录作为适配部分，并把其余记录封存为外部测试。
AFDB 与 LTAFDB 的 AFIB+AFL 定义和节律边界处理一致。
无节律标注、首条标注前的范围和波形缺失分别登记，不能自动归入正常节律。
若不能确认受试者映射，明确报告按记录分组及剩余身份泄漏风险。
外部清单另登记纯阴性记录数量；若没有，不报告整条阴性记录特异性。

M1 可以先在 AFDB 完成并归档结果，外部测试不作为后续学习开发的必经调参步骤。
若提前查看某部分 LTAFDB 的策略表现，该部分转为外部开发集并登记；后续 M2/M3
不能继续把同一部分称为未见外部测试，需预留未查看记录或另找独立测试来源。

ECGFounder 官方要求遵循其 dataset.py 预处理，当前实验按用户选择使用 NeuroECG 配方。
开发阶段单列官方配方与当前配方对照，在最终冻结策略前检查感知输入分布的影响。
这项对照不阻塞固定当前配方的 M1 实验；如更换主配方，给输入另一个版本并重新运行
相关对照，不把预处理改进算成记忆或 LLM 收益。

## 10. 评价与必要消融

主指标保持 ECG-Scroll 一对一贪心 IoU >= 0.5 的事件 F1，并报告：

- 时间精确率、时间召回和负荷误差。
- 完全位于非 AF 时间的误报，以及与真值重叠但未匹配的预测。
- 每个参考事件的预测碎片数量、长事件的中断次数和未判断时长。
- 错误合并率、各状态停留时间、未知超时次数及末尾截断事件数。
- <30 s、30–60 s、>=60 s 事件召回。
- 起点、终点估计误差及实际确认/结束写入延迟。
- 风险—成本—覆盖率曲线、逻辑工具调用和真实推理成本。

为保持可比性保留论文的“首次与完整事件满足 IoU 的写入”延迟，但与早期报警延迟
分开报告。长事件的这项指标往往要等覆盖足够时长才成立，不能用来代表初始报警速度。
预计 10 秒模型窗口的边界分辨率会限制极短事件召回，结果需分层报告。

必要消融包括无历史状态、无证据来源/缺口、无第二通道、无质量、无 RR、无学习停止、
无审查，以及仅用相同区间合并规则。若 RR 只是日志，不将其称为参与了融合决策。
重复或同源证据不应推动置信度无依据上升，增加证据重复与矛盾注入实验。

### 10.1 固定证据与闭环决策分开比较

当前 decide() 读取 active、open_interval、support_count、last_checked_count。
换追踪器会改变调用时机，所以“新状态机 + 原函数”不能直接视为只改变记忆。

| 编号 | 设置 | 验证目的 |
|---|---|---|
| B0 | 单窗阈值 | 原始分数与边界基线 |
| B1 | 连续两窗 | 简单时间确认基线 |
| B2 | 固定双通道 | 高调用量强基线，非理论或经验性能上限 |
| B3 | 当前 Adaptive | 冻结旧追踪器与旧复核策略 |
| B4 | 简单平滑、滞回、固定间隔合并各自独立设置 | 检查延长/合并区间的贡献 |
| V1-A | 固定 B3 已取得的证据轨迹，仅替换追踪器 | 隔离事件维护的贡献 |
| V1-B | 新追踪器驱动状态感知规则复核，闭环执行 | 测量新的证据获取与追踪组合效果 |

V1-A 逐窗重放 B3 相同的工具返回、时间和失败状态；事件决策由新追踪器重新生成，
不沿用 B3 的最终 support/negative 标签。未出现在 B3 轨迹中的证据不可补入。
为隔离状态转移，已有证据的解释规则也冻结，并明确其可用字段。
该结果仅表示旧调用分布下的追踪器效应，不代表新策略在自身调用分布中的表现。
V1-B 再独立闭环运行，在相同允许工具与预算下画成本权衡，不能只与 B3 比单一 F1。
保存轨迹哈希，核验 V1-A 与 B3 的原始证据序列及逻辑调用成本完全一致。

### 10.2 指标口径与统计

M0 先冻结指标实现及合成例子，再查看新策略结果：

- 事件主分数沿用既有一对一贪心匹配及顺序；不得为新方法另改匹配方式。
- 每个参考事件的碎片数定义为与其有正时长交集的预测区间数 n_j，报告分布及
  max(0,n_j-1)；n_j=0 的漏检另列，不能解释为良好连续性。长事件主分层为 >=60 秒，
  另报告 >=30 分钟分层和每参考 AF 小时中断数，明确中断按参考区间内部预测缺口统计。
- 错误合并率定义为与至少两个参考事件有正时长交集的预测区间数 / 全部预测区间数，
  同时报告被跨越的真实阴性时间；无预测时分母为零记 NA，并报告原始计数。
- 时间指标在独立标注有效时间内比较区间并集；未知/未判断不从分母静默删除。
  同时给出全有效时间的风险与覆盖率，及已判断部分的条件风险。波形缺失范围另列。
- Unknown Coverage = 未知/未判断时间并集 / 标注有效时间；模型评分成功率单独报告，
  不能替代决策覆盖率。无标注时间不计为真阴性。
- 起止误差用固定匹配规则计算并报告匹配数量、漏检和截断数量；不能仅挑边界好的匹配。
- 早期报警延迟按参考起点到首次已发出的确认记录的时间差计算，归属采用冻结的
  预测关联规则；未报警事件单列，不能从结果消失。流结束截断不算真实结束确认。
- 各工具类型的调用数分别列出，并报告每小时额外调用、实测单次耗时和真实按需模式
  总耗时。预计算缓存的回放耗时不能作为实际模型节省。

按记录进行配对 Bootstrap，保存随机种子、重采样次数并报告 95% 区间。
已知同一受试者多记录时按受试者聚类重采样。不能把相邻十秒窗视为独立样本；
同时报告微平均、记录宏平均和失败记录，避免只展示总体收益。

### 11.1 执行顺序与阶段判断

近期依次做 M0 → M1-A → M1-B → M1-C，形成可独立验证的规则事件追踪版本。
M1-B 先隔离问题来源，再做 M1-C；无需等待大型网络、LLM 或预处理新配方实验。
M2 在证据/事件接口与标签协议稳定后开始；M3 复用同一接口与预算，必须保留小模型对照。
M4 对需要外部检验的冻结版本执行；若提前外测 M1，遵守第 9 节的数据封存规则。

工程验收要求功能、因果权限、证据追溯和异常处理通过检查；科学结论另外依据实验。
不把“碎片、短事件召回、F1 同时提高”写成功能完成条件。研究上按预登记的风险、
延迟和成本容忍度判断 Pareto 权衡，不为达标而反复调整外部测试参数。
若新状态机只扩大区间、学习策略未优于规则或 LLM 未优于小模型，保存失败报告，
据此调整后续研究范围；不能把假设未获支持描述为已经证明有效。

建议在现有 ecg_agent 下增加 evidence.py、belief.py、event_state.py、review_policy.py、
review_learning.py 和对应评测入口。实施时按实际复用情况合并模块，避免重复已有运行时。
工具继续在 toolkit 注册并由 ToolSession 执行，标签只存在于离线构建/评价侧。

每阶段保存配置、数据与权重哈希、代码版本、训练/校准/测试记录 ID、轨迹和指标。
源代码测试重点覆盖未来变化不影响已有输出、失效证据处理、预算、重复证据、
确认时刻与估计边界分开、已确认事件短暂冲突、持续正常后的真实结束及重试一致性。

## 12. 论文贡献的证据要求

PoS 可借鉴显式信念、目标缺口和一致性维护。它提供推理时的框架，本项目拟研究的
增量是与真实波形证据关联的事件状态、风险可校准的复核停止和有限预算下的证据价值学习。

仅有滞回或间隔合并收益时，结论应限定为事件追踪工程改进。
学习模型优于固定复核且在外部数据成立时，支持证据获取与停止策略的研究贡献。
LLM 未优于小模型时保留该结果，不把接入 LLM 本身计作算法贡献。
