# 已确认事件的终点复核

在两导联规则已确认关闭后，系统可以复核估计终点。原始关闭决定和发布时刻保留。终点附近四个已经到达的十秒窗提供八个分数。补测使用以原估计终点为中心的十秒窗，每次复核实测两个导联。缺失、记录开头不足四窗或未到达的证据均不能用于修订。

数值估计器使用 14 条 AFDB 拟合记录中的 82 个已匹配终点训练。仅在这批记录上拟合岭回归和双导联分歧门槛。两类回归分别使用原窗、原窗加错位窗。输出保留决定时刻，估计区间须为正长度。测试时扫描全部记录，对每次关闭运行，不使用参考标签选择复核对象。

在八条预留 AFDB 记录上比较固定十秒网格、仅原窗校准、按导联分歧补测、全部补测。Qwen 按需组接受相同八个原窗分数，由它选择是否测量，之后沿用相同估计器。随机对照按记录匹配请求数量。报告所有预测的 TP、FP、FN、Micro F1、非目标报警秒数与遗漏目标秒数，以及原规则已匹配事件的终点绝对误差及分母。时点定位收益与新增事件发现应分别解释。以实际调用次数与模型用时报告成本。

外部验证预设为八条 LTAFDB 记录，每条连续两小时。排除此前三轮片段实验选过的 24 个记录编号；按固定散列选择记录和起始时刻，选择过程只使用记录编号和长度。每个片段均从空状态开始，评分时裁切独立参考标注及有效范围。先比较冻结的数值估计器和非 LLM 选测规则。外部回放中固定取得所有符合条件的错位分数供配对重放，分别报告实际测量和各策略需要的测量数，缓存回放不得用作实时加速证据。
