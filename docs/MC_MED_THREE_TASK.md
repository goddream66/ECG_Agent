# 三任务入口

只导出 AF、心率过快、心率过慢；独立质量状态。默认命令 bash ops/server/run_mcmed_labeling.sh 只显示协议；加 --run 从已经核验的 v0.4.0 证据生成 v0.5.0 三任务结果。可用 --source-batch 指定另一个已有证据批次；本入口不扫描新患者。原150类入口保留为历史证据采集功能，不是当前三任务标注入口。AF 的0.4/0.6阈值仅研究候选规则，非校准结果。心率为原始RR中位数对应的速率，快>100、慢<60；不推断窦性起源。质量复查使任务不确定但保留提议。30秒为本版连续候选区间的研究持续时间规则，短候选不删除。
